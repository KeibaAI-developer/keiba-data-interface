# レース時刻表

指定した日付の全レースの時刻表。レース数の行数のDataFrame（レースコード昇順）。開催が無い日は0行。

関数: `DataInterface.get_race_schedule()`

対応元:
- mykeibadb: `RACE_SHOSAI`（データ区分が9のレース中止と、中央競馬以外（競馬場コードが01〜10以外）のレースは含めない）
- scraping: `RaceScheduleScraper.get_race_schedule()`（netkeibaのレース一覧ページに載っているレースをそのまま返す。中止の判定はしない）

| カラム名 | 型 | scraping | mykeibadb | 説明 | 例 | 差分A | 差分B |
|----------|----|----------|-----------|------|----|------|------|
| レースコード | str | ○ | ○ | 年+月日+競馬場コード+回次+日次+レース番号の16桁 | "2025040609020411" | ○ | |
| 競馬場コード | str | ○ | ○ | 該当レース施行競馬場。[コード表2001](../CODE_TABLE.md#KEIBAJO_CODE)参照 | "09" | | |
| レース番号 | int | ○ | ○ | 1〜12 | 11 | | |
| 発走時刻 | str | ○ | ○ | "HH:MM"形式。未設定は欠損 | "15:40" | | |
| 競走名 | str | ○ | ○ | mykeibadbは競走名本題（特別競走・重賞のみ設定）、scrapingはレース一覧ページのレース名 | "大阪杯" | ○ | |

## 差分A: プロバイダー間の既知差分

| カラム | 内容 | レースコードの例 |
|--------|------|------|
| レースコード | 中止レースの扱いが異なる。mykeibadbはデータ区分が9のレースを含めないため、開催中止の日は0行になる。scrapingはレース一覧ページに載っているレースをそのまま返し、中止の判定をしない | "2026020908020411" |
| 競走名 | mykeibadbで競走名本題が設定されるのは特別競走・重賞のみで、一般競走は空文字になる。scrapingは「2歳未勝利」のような条件名を返す | "2025122806050801" |
| | 特別競走でもscrapingはレース一覧ページの表記のため全角6文字で切り詰められる（mykeibadb "グッドラックハンデキャップ" → scraping "グッドラック"） | "2025122806050809" |

## 差分B: mykeibadbテーブルとの差分

なし
