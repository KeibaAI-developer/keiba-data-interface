# 出走別着度数

指定レース出走時点の各馬の累積着回数（1着〜5着・着外の6区分、中央のみ）。出走頭数分の行数のDataFrame（血統登録番号昇順）。

関数: `DataInterface.get_chakudosu()`

対応元:
- mykeibadb: `SHUSSOBETSU_KEIBAJO` + `SHUSSOBETSU_KYORI` + `SHUSSOBETSU_BABA`（血統登録番号で結合）
- scraping: 各馬のraw馬柱（`HorsePageScraper.get_past_performances()`）から対象レース出走時点の
  条件別着回数を自前集計する。中央・対象レース開催日より前の行のみを対象とする。
  着順が数値の行に加え、競走中止（着順NaN・異常区分="中止"）の行も着外として集計する。
  回り（右/左/直）は馬柱に含まれないため競馬場・芝ダ・距離から導出する
  （新潟芝1000mのみ「直」の例外）。中央出走歴のない馬は着回数カラムをすべて0にする
  （mykeibadbはSHUSSOBETSUテーブルに0埋めレコードを持つため）。

| カラム名 | 型 | scraping | mykeibadb | 説明 | 例 | 差分A | 差分B |
|----------|----|----------|-----------|------|----|------|------|
| レースコード | str | ○ | ○ | 開催年+月日+競馬場コード+回次+日次+レース番号 | "2025050206050811" | | |
| 血統登録番号 | str | ○ | ○ | 生年(西暦)4桁＋品種1桁＋連番5桁 | "2022105081" | | |
| 馬名 | str | ○ | ○ | 通常全角18文字 | "ミュージアムマイル" | | |
| {競馬場}{芝/ダ/障}1着〜{競馬場}{芝/ダ/障}着外 | int | ○ | ○ | 競馬場別着回数（中央10場×芝・ダ・障の30プレフィックス、各6区分=180カラム） | `札幌芝1着`, `東京ダ着外`, `中山障3着` | | |
| {芝/ダ}{距離区分}1着〜{芝/ダ}{距離区分}着外 | int | ○ | ○ | 距離別着回数（芝・ダ×距離区分9区分の18プレフィックス、各6区分=108カラム）。距離区分は`1200以下`/`1201-1400`/`1401-1600`/`1601-1800`/`1801-2000`/`2001-2200`/`2201-2400`/`2401-2800`/`2801以上` | `芝1200以下1着`, `ダ1801-20003着`, `芝2801以上着外` | | |
| {芝/ダ}{直/右/左}1着〜障害着外 | int | ○ | ○ | 馬場別着回数（芝・ダ×直・右・左+障害の7プレフィックス、各6区分=42カラム） | `芝右1着`, `ダ左着外`, `障害2着` | | |
| {芝/ダ/障}{良/稍/重/不}1着〜{芝/ダ/障}{良/稍/重/不}着外 | int | ○ | ○ | 馬場状態別着回数（芝・ダ・障×良・稍・重・不の12プレフィックス、各6区分=72カラム） | `芝良1着`, `ダ稍4着`, `障不着外` | ○ | |

各着回数カラムはすべて int 型。一部のテーブルにのみレコードが存在する馬は、欠損したテーブル由来のカラムがNaNになる。

## 差分A: プロバイダー間の既知差分

| カラム | 内容 | レースコードの例 |
|--------|------|------|
| 障{良,稍,重,不}{1着〜5着,着外}（24カラム） | scraping（raw馬柱）とmykeibadb（`SHUSSOBETSU_BABA`）で障害レースの馬場状態の値が一致しない場合がある。`KNOWN_DIFF_HORSE_MASTER`の障害馬場状態と同じ root cause。中山大障害2024自体が対象レースの場合に加え、対象レースは障害レースでなくとも出走馬が過去に障害レースを走っている場合（アイビスSD2025）にも発生する | "2024122106050710", "2025080304020407" |
