# 出走別着度数

指定レース出走時点の各馬の累積着回数（1着〜5着・着外の6区分、中央のみ）。出走頭数分の行数のDataFrame（血統登録番号昇順）。
scrapingプロバイダーには対応するデータソースが存在しないため、`DataNotFoundError` を送出する。

関数: `DataInterface.get_chakudosu()`

対応元:
- mykeibadb: `SHUSSOBETSU_KEIBAJO` + `SHUSSOBETSU_KYORI` + `SHUSSOBETSU_BABA`（血統登録番号で結合）
- scraping: なし（`DataNotFoundError`）

## キーカラム

| カラム名 | 型 | scraping | mykeibadb | 説明 | 例 |
|----------|----|----------|-----------|------|----|
| レースコード | str | × | ○ | 開催年+月日+競馬場コード+回次+日次+レース番号 | "2025050206050811" |
| 血統登録番号 | str | × | ○ | 生年(西暦)4桁＋品種1桁＋連番5桁 | "2022105081" |
| 馬名 | str | × | ○ | 通常全角18文字 | "ミュージアムマイル" |

## 着回数カラム

すべて int 型。各条件プレフィックスに着順サフィックス（`1着` / `2着` / `3着` / `4着` / `5着` / `着外`）を連結した402カラム。
一部のテーブルにのみレコードが存在する馬は、欠損したテーブル由来のカラムがNaNになる。

### 競馬場別（`SHUSSOBETSU_KEIBAJO`、180カラム）

競馬場（札幌・函館・福島・新潟・東京・中山・中京・京都・阪神・小倉）× 面（芝・ダ・障）の30プレフィックス。

例: `札幌芝1着`, `東京ダ着外`, `中山障3着`

### 距離別（`SHUSSOBETSU_KYORI`、108カラム）

面（芝・ダ）× 距離区分（`1200以下` / `1201-1400` / `1401-1600` / `1601-1800` / `1801-2000` / `2001-2200` / `2201-2400` / `2401-2800` / `2801以上`）の18プレフィックス。

例: `芝1200以下1着`, `ダ1801-20003着`, `芝2801以上着外`

### 馬場別（`SHUSSOBETSU_BABA`、42カラム）

面（芝・ダ）× 回り（直・右・左）+ 障害の7プレフィックス。

例: `芝右1着`, `ダ左着外`, `障害2着`

### 馬場状態別（`SHUSSOBETSU_BABA`、72カラム）

面（芝・ダ・障）× 馬場状態（良・稍・重・不）の12プレフィックス。

例: `芝良1着`, `ダ稍4着`, `障不着外`
