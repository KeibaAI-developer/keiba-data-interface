# 単複票数情報

単勝・複勝の票数（投票数）。出走頭数分の行数のDataFrame。scrapingプロバイダーでは取得できない（`DataNotFoundError`）。

関数: `DataInterface.get_win_show_votes()`

対応元:
- mykeibadb: `HYOSU1_TANSHO` + `HYOSU1_FUKUSHO`（馬番ごとの票数）+ `ODDS1`（票数合計）
- scraping: なし（netkeibaに票数の掲載が無い）

票数の単位は mykeibadb のまま百円とし、円に換算しない（支持率の計算には比しか使わないため）。
`DATA_KUBUN` はレースごとに1行が更新されるため、取得時点の最新値がそのまま返る。

## 取得範囲について

票数関連のテーブルのうち本関数が対象とするのは馬番単位の単勝・複勝と票数合計のみ。枠連（組番単位）、馬連・ワイド・馬単・3連複・3連単（組番単位で最大4,896行）、時系列オッズは対象外とし、必要になった時点で別関数として検討する。
